# 客户端架构与数据边界

书坊使用统一 Flutter 桌面客户端和按能力连接的可选本机引擎。历史目录或兼容配置名不代表公有／私有双产品；不新增 Electron 客户端。

| 模块 | 职责 |
|---|---|
| `lib/pages/`、`lib/widgets/` | 工作区、编辑器、讨论、练笔及只读记录 |
| `lib/store/` | 页面状态、本地配置和工作区会话 |
| `lib/services/` | 保存与恢复、草稿快照、目标、确认偏好、上下文预算和请求记录 |
| `lib/api/` | 能力握手、工作区身份绑定及引擎 HTTP 协议 |
| `lib/theme/` | 中文排版、颜色、间距、动效和主题 |
| `windows/` | Windows 原生宿主 |

## 作者方向

作品目标、作者明确确认的偏好、原稿与改稿案例、模型观察及训练规则分别表示。模型观察不能自行变成有效偏好；撤销后，新的请求不应继续采用旧偏好。历史练笔保存自己的快照，不按新偏好改写过去的证据。

上下文来自当前编辑草稿并受 UTF-16 字符预算约束；不将它描述为模型 token 窗口。直连与引擎接收同一冻结上下文。参考原文按数据处理，较早的模型回答不视为作品事实。

## 工作区与连接

保存任务绑定实际工作区、作品和章节。切换前等待保存；旧会话的模型回复不能写入新工作区。引擎需报告工作区与实例身份及可用能力，工作区不匹配的请求不自动重放。服务响应、握手和模型完成均不证明训练 worker 可用。

应用可以按配置启动本机引擎，但进程宿主生命周期仍待完善。引擎源码和 Python 运行时不在本客户端仓库中。

## 调用与成本

客户端在网络发送前追加请求准备与开始事件，终态落盘后再确认回复收齐。失败、超时和中断不自动切换通道或重试。只有服务报告的用量才记录为已报告；未知费用不补为零。

本地请求记录是核查证据，不是供应商账单，不保证服务端只执行一次，不恢复原回复。诊断界面只读且不提供重放按钮。
